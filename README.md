# Учебный frontend-проект — КР №3

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема КР №3: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

`kr3-responsive-shop` — это адаптированная версия проекта КР №1
(`kr1-html-css-shop`), дополненная отдельным файлом `css/responsive.css`
и responsive-разметкой. Проект КР №2 на Bootstrap **не используется**:
цель — показать самостоятельное владение адаптивной вёрсткой.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `contacts.html` — контактная информация;
- `product.html` — карточка товара с таблицей характеристик;
- `order.html` — форма оформления заказа;
- `css/style.css` — базовые стили;
- `css/responsive.css` — адаптивные стили (Mobile First);
- `js/main.js` — файл JavaScript (модалка + валидация);
- `images/` — папка для изображений;
- `.gitignore`;
- `README.md`.

## Подход

**Mobile First.** Базовые стили рассчитаны на мобильный экран.
Расширения добавляются через `@media (min-width: ...)`.

Точки перелома:

- `768px` — планшет: горизонтальное меню, sticky-шапка, 2 колонки карточек, боковой фильтр каталога, 2 колонки в форме;
- `1024px` — desktop: 3 колонки карточек.

## Что адаптировано

- **Шапка и навигация:** колонка на мобильном → строка с `flex-wrap` на планшете;
  `position: sticky` включён только с 768px.
- **Hero-блок:** адаптивные отступы и типографика через `clamp()`.
- **Сетка карточек (`products-grid`):** 1 → 2 → 3 колонки.
- **Каталог (`catalog-layout`):** вертикальный стек (товары → фильтры) на мобильном,
  Grid `270px + 1fr` на планшете и desktop.
- **Изображения:** `max-width: 100%`, `srcset`, `sizes`, `width`/`height`,
  `loading="lazy"`, `aspect-ratio` в CSS. Главное изображение товара — `<picture>`
  с `media`-запросами.
- **Форма заявки:** `min-height: 44px` у полей, `font-size: 16px` на мобильном,
  кнопки на всю ширину, 2-колоночная сетка на планшете,
  полноширинные поля через модификатор `order-form__field--wide`.
- **Таблица характеристик:** обёрнута в `.table-wrapper` с `overflow-x: auto`.
- **Кнопка «Наверх»:** оформлена (класс `.scroll-top-btn`).

## Используемые технологии

- HTML5 (семантика, viewport, `<picture>`);
- CSS (Flexbox, Grid, media queries, `clamp()`, `minmax()`, responsive images);
- JavaScript (модальное окно, валидация формы);
- Git / GitHub.

## Проверка

- DevTools → Responsive Mode: 375, 768, 1024, 1280.
- Горизонтальный скролл отсутствует.
- Изображения не выходят за пределы контейнеров.
- Форма и таблица не ломают ширину страницы.
- Sticky-шапка не перекрывает модальное окно (dialog использует top layer).

## Практическое занятие №13: Аудит доступности (A11y) и Lighthouse

В рамках работы была проведена проверка сайта на доступность и исправлены следующие проблемы:

1. **Семантика и навигация**: Для текущих страниц в меню добавлен атрибут `aria-current="page"`.
2. **Клавиатурная навигация**: Добавлена скрытая ссылка «Перейти к основному содержимому» (`.skip-link`), которая появляется при первом нажатии клавиши `Tab`.
3. **Фокус**: Добавлены стили `:focus-visible` с четкой обводкой для всех интерактивных элементов (ссылки, кнопки, поля форм).
4. **Контрастность**: Цвета текста (`--color-text`, `--color-muted`, `--color-primary`) заменены на более контрастные для соответствия стандартам WCAG.
5. **Формы**: Добавлены текстовые пояснения об обязательных полях, проверено соответствие `label` и `id`.
6. **Таблицы**: Для первой колонки таблицы характеристик использован тег `<th scope="row">` для правильного чтения экранными дикторами.

**Lighthouse-аудит**: Оценка доступности (Accessibility) составляет 97/100. Скриншот отчета приложен в папке `images/` (или прикреплен к Pull Request).
